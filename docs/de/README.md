# NEO Accessibility – Dokumentation

NEO Accessibility ergänzt eine Contao-Website um ein Barrierefreiheits-Panel.
Eine Schaltfläche (oder ein Link) öffnet es; Besucher wählen Hilfen zur
Darstellung für sich — größere Schrift, eine lesbare Schrift, andere Farben,
eine Lesemaske, Vorlesen und mehr — oder eine von sechs Schnellauswahlen. Die
Auswahl bleibt im Browser des Besuchers.

Das Panel bietet Hilfen zur Darstellung. Es macht eine Website nicht
barrierefrei: Das entsteht in der Website selbst (Aufbau, Texte, Farben,
Formulare, Tastaturbedienung).
