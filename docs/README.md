# Documentation · Dokumentation

The documentation of NEO Accessibility comes with the extension, in two
languages with the same pages. English is the reference language.

Die Dokumentation von NEO Accessibility liegt der Erweiterung bei, in zwei
Sprachen mit denselben Seiten. Leitsprache ist Englisch.

| Language · Sprache | Start here · Hier beginnen |
| --- | --- |
| English | [docs/en/README.md](en/README.md) |
| Deutsch | [docs/de/README.md](de/README.md) |

Who reads what · Wer was liest:

- Installing and setting up (agency, administrator): installation, setup,
  permissions, customising, privacy, troubleshooting.
- What visitors find in the panel (for the website's help or accessibility
  statement): usage.
- Installieren und einrichten (Agentur, Administrator): Installation,
  Einrichtung, Rechte, Anpassen, Datenschutz, Fehlersuche.
- Was Besucher im Panel finden (für Hilfe oder Erklärung zur
  Barrierefreiheit der Website): Bedienung.
