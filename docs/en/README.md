# NEO Accessibility – documentation

NEO Accessibility adds an accessibility panel to a Contao website. A button
(or a link) opens it; visitors choose display aids for themselves — larger
text, a readable font, other colours, a reading mask, read aloud and more —
or one of six quick options. The choice stays in the visitor's browser.

The panel offers display aids. It does not make a website accessible: that
comes from the website itself (structure, texts, colours, forms, keyboard
use).
